PROJECT 01

618大促商家价格策略与促销效果综合复盘

基于DID双重差分方法，量化618巅峰价活动的真实提升效果（剥离日历效应），覆盖大家电/小家电/家装/家居四个行业 × H1-H4四个商家层级，输出分层运营策略建议。核心发现：大家电H1-H2的DID效应最强（坑产+24.3pt），但H4拖累整体指标；家居行业统一策略效果有限，需按细分品类差异化定价。

DID双重差分 因果归因 分层分析 大促复盘
PROJECT 02

跟价运营动作 → 成交转化量化分析

通过线性回归建模，量化各行业"跟价次数→成交增量"的弹性系数和相关性强度，为运营资源分配提供数据依据。同时验证跟价对高价率的压制效果有限，高价率与成交无线性关系，建议运营重心从"压高价率"转向"提升跟价→成交转化效率"。

线性回归 相关性分析 运营ROI 数据驱动决策
PROJECT 03

国补政策对商家定价行为的影响分析

分析国补（消费品以旧换新补贴）对参与商品价格的净效应，以及退出补贴后商家的涨价行为差异。发现三个行业呈现三种不同的涨价模式（大家电"高依赖涨价"、家装"等比回吐"、小家电"自行吸收"），并识别天猫家装新增商品的"先涨后补"风险信号。

同比净效应 价格分布分析 政策评估 商家行为洞察
PROJECT 04

25年Q1非食品类供给经营分析

非食品BP商分视角，结论先行、数据驱动的Q1供给经营诊断。向内看：区域坑产对比定位华中标杆（165元/SKU/日，+29% vs 均值），拆解品牌结构+量贩配置+新品打法三大差异根因，输出跨区域迁移方案（月增量+480万）。向外看：按价格带/规格/子品类三维度对标ddmc识别系统性缺口（量贩组合装-48%、20-50元品牌家庭装-29%），叠加tbmc 3.25退出品牌个护份额窗口（~1,300万/月），输出P0/P1分级策略清单。

区域对标分析 坑产效率拆解 竞对缺口定位 tbmc退出窗口
